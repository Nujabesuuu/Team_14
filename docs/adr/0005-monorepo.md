# ADR-0005: Монорепозиторій для клієнта, бекенду й документації

**Статус:** прийнято · 2026-10-27

## Контекст

У продукту три частини: мобільний клієнт, API і документація з промптами для курсу. Команда з 4 людей, кожен торкається щонайменше двох частин (тімлід пише і клієнт, і бекенд; BA/QA пише вимоги й тести). Контракт API змінюється разом із клієнтом, а викладач перевіряє все за одним посиланням на GitHub.

## Варіанти

| Критерій | **Монорепозиторій `apps/*`** | Окремі репозиторії (api, web, docs) | Один застосунок (бекенд роздає зібраний фронтенд) |
|---|---|---|---|
| Зміна контракту API + клієнта | Один PR, одна ревізія | Два PR, треба синхронізувати версії | Один PR |
| Здача курсу (одне посилання) | Так | Ні, три посилання | Так |
| CI | Один workflow, дві незалежні джоби | Три окремі налаштування | Одна джоба, але змішані інструменти |
| Незалежний запуск частин | Так, кожна папка самодостатня | Так | Ні, фронтенд не запускається окремо з hot reload |
| Збірка під Android | Окремо з `apps/web` | Окремо | Складніше: фронтенд вшитий у бекенд |
| Інструменти монорепо (Nx, Turborepo) | Не потрібні: лише 2 застосунки на різних мовах | Не потрібні | Не потрібні |

## Рішення

Один репозиторій без інструментів монорепо:

```
apps/api/      FastAPI-бекенд (власний pyproject.toml, тести, Dockerfile)
apps/web/      React-клієнт (власний package.json, тести, Dockerfile, Capacitor)
docs/          вимоги, технічний аналіз, ADR, контракти
prompts/       промпти кожної контрольної точки
dev.py         запуск усього однією командою без Docker
docker-compose.yml   запуск усього однією командою з PostgreSQL
CLAUDE.md      правила для ШІ-асистента
```

Кожна папка в `apps/` не залежить від іншої під час збірки. Їх пов'язує лише HTTP-контракт у [docs/contracts/](../contracts/).

## Наслідки

- Зміна контракту, бекенду і клієнта йде одним PR, а CI перевіряє обидві частини.
- Спільних типів між Python і TypeScript немає: `apps/web/src/api/types.ts` пишеться вручну за контрактом. Ризик розбіжності закриваємо правилом у [CLAUDE.md](../../CLAUDE.md): спершу контракт, потім код по обидва боки.
- Python-залежності і Node-залежності встановлюються окремо. `dev.py` ховає це за однією командою.

## Коли переглянути

Якщо з'явиться третій застосунок (наприклад, окрема адмін-панель модерації) або спільні пакети. Тоді варто згенерувати TypeScript-типи з OpenAPI і, можливо, взяти Turborepo.
