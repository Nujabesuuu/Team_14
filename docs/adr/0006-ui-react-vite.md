# ADR-0006: React 19 + TypeScript + Vite + Zustand для інтерфейсу

**Статус:** прийнято · 2026-10-27 (фіксує вибір, зроблений у прототипі 2026-09-18)

## Контекст

Інтерфейс — головне в демо: свайпи, анімований метч, розмиття фото, чат у реальному часі. Клієнт має працювати в браузері (демо на двох вкладках) і збиратись в Android ([ADR-0002](0002-capacitor-over-react-native.md)). Тімлід має досвід з React, решта команди — ні з чим конкретним, тож важить, наскільки добре ШІ-асистент генерує код у цьому стеку і наскільки його легко перевірити.

## Варіанти

| Критерій | **React + Vite** | Vue 3 + Vite | Angular | Flutter |
|---|---|---|---|---|
| Досвід команди | Тімлід | Немає | Немає | Немає |
| Якість ШІ-генерації | Найбільше прикладів, передбачуваний код | Добра | Середня, багато шаблонного коду | Добра, але інша мова (Dart) |
| Час до першого екрана | Хвилини | Хвилини | Довше: модулі, DI | Довше: SDK, емулятор |
| Анімації й CSS-ефекти дизайн-системи (`clip-path`, framer-motion) | Так | Так | Так | Свої примітиви, CSS не переноситься |
| Android з того самого коду | Через Capacitor | Через Capacitor | Через Capacitor | Нативно |
| Тести | Vitest + Testing Library | Vitest | Karma/Jest | flutter_test |

**Стан застосунку:** Zustand порівнювали з Redux Toolkit і React Context. Redux дає більше шаблонного коду без вигоди для 4 сторів, а Context перемальовує все дерево на кожне повідомлення чату. Zustand — це 4 невеликі стори (`auth`, `events`, `matches`, `chat`), кожен сам підписується на свої WebSocket-події.

**Збірка:** Vite замість Create React App (не підтримується) і Next.js (SSR не потрібен мобільному клієнту і заважає статичній збірці під Capacitor).

## Рішення

React 19 + TypeScript (strict) + Vite + React Router 7 + Zustand + framer-motion; стилі — CSS-змінні дизайн-системи Phantom UI з Tailwind для утиліт. Перевірки: `tsc -b`, `oxlint`, Vitest.

## Наслідки

- Один стек для браузера, PWA і Android.
- Типи відповідей API пишуться вручну в `src/api/types.ts`. Їх треба оновлювати разом із [контрактом](../contracts/api.md).
- Анімації framer-motion поводяться нестабільно під StrictMode (дефект, знайдений на КТ5, див. [ai-log](../ai-log.md)). Правило: візуальні зміни перевіряти в браузері, а не лише тестами.

## Коли переглянути

Якщо продуктивність WebView на слабких Android-пристроях стане помітною в чаті або свайпах — тоді React Native для мобільної версії.
