# Дизайн-система «Phantom UI»

Референс — візуальна мова Persona 5 Royal: агресивний контраст, скошені площини, «рваний» друк, чорний + червоний + папір. Ми беремо мову, а не асети: усі шрифти, форми й персонажі оригінальні.

Джерело істини — `apps/web/src/design-system/tokens.css`. Типізована копія для JS — `tokens.ts`.

## Кольори

| Токен | Значення | Роль |
|---|---|---|
| `--ink` | `#0A0A0A` | Фон, «чорнило» |
| `--ink-2` | `#141414` | Панелі на фоні |
| `--paper` | `#F4F1EA` | Картки, текст на чорному |
| `--blood` | `#E60012` | Головний акцент: CTA, активний стан, wipe |
| `--blood-deep` | `#9B000C` | Тіні акценту |
| `--ash` / `--ash-2` | `#2A2A2A` / `#3D3D3D` | Рамки, вимкнене |
| `--chalk` | `#FFFFFF` | Текст на червоному |
| `--gold` | `#F5C518` | **Тільки** Teamate+ і Game Date |

Правило пропорцій: ~70 % чорного, 20 % паперу, 10 % червоного. Золото — виняток, який сигналізує «преміум».

## Типографіка

- **Anton** (`--font-display`) — заголовки капсом, `skewX(-8deg)` через клас `.skew`, `line-height: 0.9`.
- **Barlow** (`--font-ui`) — текст.
- **Barlow Condensed 700/800** (`--font-cond`) — лейбли, чипи, кнопки; `letter-spacing: 0.08em`, капс.

## Форми

Усі «фірмові» силуети — `clip-path` полігони з `tokens.css`:

| Токен | Де |
|---|---|
| `--cut-card`, `--cut-card-alt` | `Panel`, картки івентів (парні/непарні чергуються), картка Discover |
| `--cut-button` | `PhantomButton`, рядки учасників, список метчів |
| `--cut-chip` | `Chip`, кнопка «назад», квадрати вибору маски |
| `--cut-tag` | Лейбл поля вводу |
| `--cut-bubble-them` / `--cut-bubble-me` | Бульбашки чату (паралелограм з «хвостом») |

**Ефект «зміщеного друку»:** під кнопкою/панеллю лежить така сама фігура іншого кольору, зміщена на 4–6 px (`PhantomButton`, `Panel ghost`, `EventCard`). Це головний повторюваний мотив.

## Рух

- **Wipe** між екранами: червона діагональна плашка `scaleX 1 → 0` за 260 мс + зсув контенту на 24 px (`design-system/Wipe.tsx`).
- **Поява списків:** stagger 40–50 мс на елемент, зсув по X + невеликий skew, що «випрямляється».
- **Екран метчу:** дві маски влітають з країв (spring), заголовок «стемпується» зі scale 3 → 1 з поворотом −6°.
- **Стемпи** `LIKE`/`NOPE` у Discover прив'язані до відстані перетягування.
- **Reveal:** `filter: blur()` анімується 900 мс, зображення трохи збільшене (`scale(1.15)`), щоб краї не «протікали».

Обмеження: усередині `AnimatePresence` не використовуємо `initial` на прямих дітях (під React StrictMode анімація не стартує). Для входу таких елементів — CSS-клас `.deal-in`.

## Аватари-маски

8 оригінальних SVG у `src/avatars/`: `raven`, `jester`, `kitsune`, `marionette`, `sentinel`, `vesper`, `nomad`, `oracle`. Кожен — плоский силует папір + чорнило з одним `accent`-кольором, який користувач обирає з `accentPalette`. Використання: `<Avatar avatar="kitsune" accent="#E60012" size={48} />`.

Маски заміняють фото всюди, де фото ще не розкрите: картки, списки, чат, екран метчу.

## Мобільна рамка

`.phone` обмежує ширину `--phone-w: 430px`; на десктопі малює телефонну рамку з червоною тінню на смугастому фоні, на мобільному — full-bleed. `--safe-top`/`--safe-bottom` беруть `env(safe-area-inset-*)` для Capacitor.
