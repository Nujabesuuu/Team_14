# Teamate

> Застосунок для знайомств між геймерами: люди спочатку шукають тіммейта і грають разом, а симпатія чи дружба з'являється вже в процесі гри, а не після оцінки фото.

**Статус:** контрольна точка 1. Команда та стартова ідея (робоча гіпотеза, буде уточнюватись протягом курсу).

## 2. Проблема

Класичні дейтинг-застосунки (Tinder-подібні) змушують вирішувати за кілька секунд, дивлячись лише на фото. Через це:

- **сором'язливим людям та інтровертам важко почати знайомство.** Потрібно одразу підтримувати розмову «ні про що» з незнайомцем, і вже тоді оцінюють за зовнішністю;
- **немає спільного приводу для спілкування.** Холодний чат після метчу швидко згасає, бо людям немає що робити разом;
- **геймерам бракує компанії для гри.** Пошук тіммейтів розкиданий по Discord-серверах, Reddit і внутрішньоігрових чатах, де немає ні профілів, ні розкладу, ні нормального способу продовжити спілкування.

**Наша гіпотеза:** геймерам простіше зблизитись через спільну діяльність, тобто гру, ніж через свайпи по фото. Гра може стати першим кроком знайомства, а не його наслідком.

---

## 3. Цільовий користувач

- **Геймери, яким бракує компанії для гри.** Шукають дуо чи команду. Це основна мотивація прийти в застосунок.
- **Сором'язливі люди та інтроверти.** Їм важко знайомитись напряму, а через спільну активність відкриватись легше.
- **Люди, які хочуть знайти друзів або романтичного партнера через спільний інтерес.** Для них важливіші сумісність у грі й характер, ніж перше враження від фото.

---

## 4. Початкова ідея рішення

Вебзастосунок, у якому знайомство будується навколо спільної гри.

**Ключові можливості (попередньо):**

- **Профіль без фото за замовчуванням.** Користувачі бачать текстовий опис: ігри, стиль гри, інтереси й мету (тіммейт, дружба чи стосунки).
- **Ігрові івенти.** Будь-хто може створити івент, наприклад «Шукаю дуо у Valorant сьогодні о 20:00» чи «Збираю команду на кастомку в Dota 2», а інші приєднуються. Це природний привід познайомитись.
- **Свайп-інтерфейс.** Перегляд профілів та івентів у звичному форматі «вліво/вправо».
- **Вбудований чат.** Спілкування до, під час і після гри.
- **Преміум-підписка.** Відкриває перегляд фотографій інших користувачів. Коли в процесі гри виникає симпатія, з'являється бажання побачити людину.

**Позиціювання:** «Bumble для геймерів» з оберненою логікою Tinder.
Не *фото → оцінка → знайомство*, а *спільна гра → спілкування → (опційно) фото*.

## Відкриті питання для обговорення

1. **Матчинг.** За якими критеріями підбирати людей: гра, розклад, опис профілю чи комбінація?
2. **Розблокування фото.** Лише через преміум чи також безкоштовно за взаємною згодою (наприклад, після спільної гри)? Чи не суперечить платний доступ до фото ідеї «знайомства не за зовнішністю»?
3. **Приватність і згода.** Чи має користувач сам вирішувати, хто може бачити його фото?
4. **Безпека й модерація.** Як верифікувати акаунти та захищатись від фейків, якщо фото за замовчуванням приховані? Як обмежити доступ неповнолітнім (18+)?
5. **Розділення режимів.** Як розвести пошук тіммейта і романтичні знайомства, щоб не було небажаної уваги?
6. **Ігри та інтеграції.** Які ігри підтримувати на старті? Чи потрібна інтеграція зі Steam, Discord або Riot ID для підтвердження нікнейму?
7. **Формат івентів.** Лише разові чи також регулярні (наприклад, «щовівторка о 19:00»)?
8. **Конкуренти.** Чим ми відрізняємось від наявних рішень ([Kippo](https://www.kippo.com/), [GameTree](https://gametree.me/), LFG-канали в Discord)?
